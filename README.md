# Blinkit-Grocery-Data-Performance-Dashboard
Transforming 8,000+ transactional records into an executive-ready Power BI dashboard for Blinkit. Focuses on store footprint optimization, tier-based revenue analysis, and category-level inventory efficiency.

Project Goal
Identify key revenue drivers, optimize SKU allocation, and determine the most profitable store size and location tiers across Blinkit's quick-commerce supply chain.

Solution Provided
Data Engineering: Cleaned, standardized, and structured raw retail data.
Star Schema Modeling: Optimized data relationships for sub-second visual performance.
Custom DAX Framework: Created measures for dynamic KPIs, ratings, and time-series trends.
Executive UI/UX: Built a brand-aligned, interactive layout with left-sidebar filters and high-level KPI headers.

Key Visuals Included
Executive KPI Cards: Total Sales (₹1.20M), Avg Sales (₹140.99), Total Items (8,523), Avg Rating (3.92).
Outlet Establishment Line Chart: Store growth trends from 2012 to 2022 (peaking in 2018 at ₹205K).
Item Type Bar Chart: Top revenue categories led by Fruits & Vegetables (₹0.18M) and Snack Foods (₹0.18M).
Outlet Size Donut Chart: Revenue split showing Medium stores leading at ₹507.9K.
Location Tier Bar Chart: Regional performance showing Tier 3 cities generated the highest sales (₹472.13K).
Store Summary Matrix: Operational breakdown comparing Supermarket Types 1–3 and Grocery Stores.

Features & Highlights
Dynamic Slicers: Instant multi-attribute filtering by Outlet Location, Size, and Item Type.
Cross-Filtering Canvas: Re-evaluates ratings, categories, and metrics on any click.
Multi-Metric Toggles: Quick switching between Total Sales, Avg Sales, No. of Items, and Avg Rating.
